# NoCode Forge

NoCode Forge is a visual no-code UI builder (React + Vite + Tailwind) with:
- drag-and-drop canvas editing
- multi-select editing and batch actions
- undo/redo history
- theme system (built-in + custom themes)
- web and mobile (Expo) code export

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes
- Project state is persisted in localStorage.
- `?` opens the help center.
- Mobile export generates a modular Expo app structure.
